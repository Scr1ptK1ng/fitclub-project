## Жоспардың негізі

- Жоспарлау кезеңі: 08.10.2026–16.12.2026, 10 оқу аптасы.
- Команда: Айдос, Ануар, Әділбек.
- Теориялық уақыт: 150 сағат.
- Оқу жүктемесі, үйлестіру және резерв шегерілгеннен кейінгі capacity: 99 сағат.
- Жоспарланған жұмыс: 84 сағат. Қалған 15 сағат өзгеріс пен күтпеген жұмысты жабатын резерв.
- Үш инкременттің мерзімі бекітілген жоспар ретінде берілген; мазмұн capacity жетпесе төмен басымдықтағы тарихтарды кейінгі релизге жылжыту арқылы реттеледі.

Бұл құжаттар өнім әзірленді немесе тесттен өтті дегенді білдірмейді. Оқытушы, клуб өкілі және хостинг бойынша шешімдер әлі расталмаған сыртқы тәуелділіктер ретінде көрсетілген.
