# Команда топологиясы және RACI

FitClub үшін бір stream aligned команда таңдалды. Үш студент клиентке қызмет көрсету ағынына басынан аяғына дейін жауап береді. Бөлек platform немесе complicated subsystem командасын құру осы көлемде қосымша келісу шығынын тудырады. Хостинг, оқытушы және болашақ клуб өкілі командадан тыс тәуелділіктер болып қалады.

Белгілер: R — орындайды, A — соңғы жауапты, C — кеңес береді, I — хабардар.

| Артефакт немесе нәтиже | Айдос | Ануар | Әділбек | Оқытушы |
|---|---|---|---|---|
| Өнім шекарасы және бэклог | A/R | C | C | I |
| WBS және релиздер жоспары | A/R | C | C | I |
| Сыртқы тәуелділіктерді нақтылау | C | A/R | I | C |
| Деректер моделі және функционал | A/R | I | C | I |
| Қабылдау критерийлері және тест хаттамасы | C | I | A/R | I |
| NFR тексеру жоспары | C | I | A/R | I |
| Мәртебе және оқытушымен байланыс | C | A/R | I | I |
| Қорытынды демонстрация | A/R | R | R | I |
| Baseline-ды оқу жұмысы ретінде бекіту | R | C | C | A |

Әр жолда бір A бар. Оқытушы оқу нәтижесін қабылдайды, бірақ студенттердің күнделікті жұмысын орындамайды. Нақты клуб пилоты басталса, клубтан дерек иесі мен қабылдауға жауапты тұлға бөлек тағайындалады.

## Команда ішіндегі аймақтар

- Айдос: өнім басымдығы, архитектура, негізгі әзірлеу, орта және релиз дайындығы.
- Ануар: сыртқы сұрақтар, шешім журналы, оқытушымен және пайдаланушы өкілдерімен байланыс.
- Әділбек: тест дизайны, қабылдау дәлелі, ақау триажы және әзірлеуге көмек.

Қатысушы өз негізгі аймағына жауап береді, бірақ кодты қарау мен демонстрацияда екінші адам міндетті түрде қатысады. Бұл бір адамның болмауынан жұмыстың тоқтау қаупін азайтады.
