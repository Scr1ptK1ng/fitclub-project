# ЛЗ7 — Тәуекелдер және қауіпсіздік

Бұл бума FitClub жобасының ЛЗ7 нәтижелерін жинақтайды.

## Нәтиже

- 24 тәуекелден тұратын RAID тізілімі дайындалды;
- ең жоғары ұпай алған 5 тәуекел егжей-тегжейлі талданды;
- аутентификация компонентіне STRIDE моделі жасалды;
- Gitleaks және Trivy нақты іске қосылып, нәтижелері сақталды;
- жеке деректер мен AI қолданылуына арналған сәйкестік чек-парағы әзірленді;
- үш тәуекелді азайту жұмысы backlog-қа мерзімімен енгізілді.

## Маңызды шектеулер

Тәуекелдер тізімі — командалық pre-mortem сессиясына арналған бастапқы нұсқа. Команда оны талқылап, өзгерістерін тіркеуі тиіс. Өндірістік хостинг пен нақты фитнес-клуб операторы әлі бекітілмегендіктен, заңды негіз, сақтау орны және сақтау мерзімі пилотқа дейін жауапты тұлғамен расталуы керек. MVP-де AI компоненті жоқ.
