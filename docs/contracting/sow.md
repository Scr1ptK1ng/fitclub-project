# FitClub Statement of Work

Күйі: оқу жобасының жобасы, заңды келісімшарт емес. 22.10.2026.

## Тараптар және мақсат

Тапсырыс беруші/спонсор рөлін зертханалық жұмысты қабылдайтын оқытушы атқарады. Орындаушы — Ануар, Айдос және Әділбек командасы.

Мақсат — фитнес-клуб әкімшісіне клиент, абонемент, кесте, жазылу, қатысу және төлем мәртебесін бір web MVP ішінде басқаруға мүмкіндік беретін оқу шешімін кезеңдеп дайындау.

## Нәтижелер

| ID | Нәтиже | Қабылдау критерийі | Иесі |
|---|---|---|---|
| D1 | SoW | мақсат, scope, deliverable, acceptance, change және rights бар | Ануар |

| D6 | QA дәлелі | формула қатесі жоқ; сома арифметикалық reconcile жасайды | Әділбек |

## Scope ішінде

- клиент профилі, абонемент және мәртебе;
- кесте, жазылу/бас тарту және қатысу;
- төлем мәртебесі және негізгі есеп;
- admin, manager және trainer рөлдері;
- қазақша/орысша web MVP және PostgreSQL.

## Scope сыртында

- native mobile app;
- толық бухгалтерия және payment acquiring;
- биометрия және турникет;
- AI/ML;
- күрделі көп филиалдық схема;
- 24/7 production SLA және production-дағы нақты клиент дерегі.

## Қабылдау тәртібі

1. Нәтиже иесі файл мен evidence-ті GitHub-қа салады.
2. Әділбек acceptance criteria, formula және link-ті тексереді.
3. Ануар оқытушыға қысқа мазмұн мен сілтеме береді.
4. Оқытушы қабылдайды немесе ескерту береді.
5. Scope, мерзім не бюджетке әсер ететін ескерту change request ретінде жүргізіледі.

Оқытушының жауап мерзімі бекітілмеген; қабылдау келесі келісілген қорғау кезінде жасалады.

## Өзгеріс процесі

1. Ануар сұраныстың не және неге өзгеретінін issue/decision log-қа жазады.
2. Айдос пен Әділбек scope, мерзім, бюджет, қауіп және acceptance әсерін бағалайды.
3. Оқытушы қабылдайды, қабылдамайды немесе кейінге қалдырады.
4. Иесі backlog, жоспар, бюджет, тәуекел және құжат нұсқасын жаңартады.
5. Әділбек жаңа критерий бойынша evidence тексереді.

## Нәтижеге құқық

Ұсынылатын оқу шарты: студенттер авторлығын және бастапқы кодқа құқықтарын сақтайды; оқытушы нәтижені қарауға, бағалауға және оқу мақсатында пайдалануға құқылы; үшінші тарап компоненттері өз лицензияларымен қалады; production келісімінсіз нақты клуб дерегі репозиторийге салынбайды. Нақты келісім жасалса, бұл тармақтар қайта бекітіледі.
