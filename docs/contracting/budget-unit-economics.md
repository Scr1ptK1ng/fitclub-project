## Unit-экономика

| Көрсеткіш | 1-жыл толық | Тұрақты пайдалану |
|---|---:|---:|
| Айлық шығын | 396 046 ₸ | 57 998 ₸ |
| Cost / active user / month | 1 320,15 ₸ | 193,33 ₸ |
| Economic effect / user / month | 936,00 ₸ | 936,00 ₸ |
| Unit margin | −384,15 ₸ | 742,67 ₸ |
| Break-even user count | 424 | 62 |

Формулалар:

- `cost/user/month = жылдық шығын / 12 / active users`;
- `effect/user/month = жылдық экономикалық әсер / 12 / active users`;
- `break-even users = CEILING(айлық шығын / effect per user per month)`.

Экономикалық әсер түсім емес: ол әкімшілік уақытын үнемдеу, сақталуы мүмкін абонемент кірісі және операциялық қатені азайту жиыны. 300 клиент, 600 операция және 3 369 600 ₸ жылдық әсер — ЛЗ3-тегі тексерілетін болжамдар.
