## Негізгі нәтиже

- 12 айлық жоспарлық бюджет: **4 752 553 ₸**.
- Бірінші жылдағы cost per active user per month: **1 320,15 ₸**.
- ЛЗ3 болжамына негізделген economic effect per user per month: **936,00 ₸**; бұл түсім емес.
- Break-even: бірінші жылы **424 клиент**, тұрақты пайдалану режимінде **62 клиент**.
- MVP үшін ұсыныс: **DigitalOcean VPS-та Ubuntu + PostgreSQL ашық стек**.
- 30 күндік айда 99% availability error budget: **3 сағат 36 минут**.

## Дерек сапасы

Жарияланған тариф пен валюта бағамының URL-ы және күні Excel-дегі «Дереккөздер» парағында берілген. Клубқа қатысты нақты статистика жоқ; ЛЗ3-тегі мәндер «Болжам» деп белгіленген. Own infrastructure бағасы толық TCO емес, өйткені электр, ISP/static IP, UPS, жеткізу, кеден және ауыстыру бағасы расталмаған.
