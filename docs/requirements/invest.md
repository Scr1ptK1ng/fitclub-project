# INVEST бойынша тексеру

v0.2, 01.10.2026. Қаралған тарихтар: US-01–US-19. Бұл құжат талаптардың құрылымын тексереді; код пен қабылдау тесттерінің өткенін растамайды.

| Қағида | Тексеру және шешім |
|---|---|
| I — тәуелсіздік | Әр тарих жеке тексеріледі; тестке аккаунт/клиент/абонемент/бронь fixture-і беріледі. Қажетті реттілік төменде көрсетілді, функционалдық тәуелділік жасырылмайды |
| N — келісуге ашық | UI орналасуы бекітілмеген. Мұздату және хабарлау тәртібі кейін келісілетін шартпен жазылған |
| V — пайдаланушыға құндылық | Барлық 19 тарихта адам рөлі, әрекеті және мақсаты бар; US-19 P1-дің еркін келу сценарийін жабады |
| E — бағаланатын | Әр тарихта 2/3/5 SP бағасы бар; сұхбаттан кейін US-04 3-тен 5-ке өсті, US-19 3 SP қосылды |
| S — шағын | US-11 сабаққа қатысумен шектелді; еркін келу US-19-ға бөлінді. Жеке кабинет толық бір үлкен тарих емес: US-18 тек өз атынан бронь жасау |
| T — тексерілетін | Әр тарихта Given–When–Then оң және теріс сценарийі, NFR байланысы бар |

## Тәуелділіктер және жұмысқа алу ережесі

| Тарих | Бастапқы шарт / тәуелділік |
|---|---|
| US-02,03,07,13 | US-01 аккаунты немесе рөлдік тест fixture-і |
| US-04–06 | Клиент/абонемент жазбасы (US-02,04 немесе fixture) |
| US-08,09 | Клиент, жарамды абонемент және сабақ (US-02,04,07) |
| US-10,11 | Топтық сабақ және бронь (US-07,08) |
| US-19 | Клиент пен жарамды абонемент (US-02,04); US-07/08 броні қажет емес |
| US-12,14 | Дерек/аудит оқиғалары немесе бекітілген тест жиыны |
| US-15–18 | Тиісті MVP негізі; келісілмеген бизнес ережесі іске асыруға дейін шешіледі |

5 SP-ден жоғары немесе бір итерацияға сыймайтын тарих жұмысқа алынбайды: алдымен пайдаланушыға көрінетін нәтиже бойынша бөлінеді. Тек UI/DB/API қабаттары бойынша бөлу жеткілікті емес.
US-04-тегі екі тариф түрі бір абонемент операциясының нұсқалары ретінде сақталды; іске асыруда көлем өссе, қайта бөлінеді.
