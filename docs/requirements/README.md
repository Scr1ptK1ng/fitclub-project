## Бекіту және өзгерістер

Ануар жауаптарды және ашық сұрақтарды жинайды; Айдос басымдық пен шекараны, Әділбек критерийлерді қайта қарайды. Нақты бекіту күні мен шешімі алынғаннан кейін ғана baseline v1.0 белгіленеді.
Өзгеріс жазбасы: CR-ID, күн, себеп, дәлел, өзгеретін US/NFR, бағалау/мерзім әсері, шешім иесі және шешімі.
Бюджет +10%, негізгі кезең 7 күннен артық кешігу не шекара өзгерісі оқытушымен келісуді қажет етеді (ЛЗ3 жарғысы). SP өсімі автоматты түрде бюджет өсімі емес.
