# FitClub UAT сценарийлері

Орта: Docker Compose демо-стенді. Әкімші: `admin`; құпиясөз тек орындаушыға беріледі. Әр сценарийдің фактілік нәтижесі [хаттамаға](uat-protocol.md) жазылады.

| ID | Алғышарт | Қадамдар | Күтілетін нәтиже |
|---|---|---|---|
| UAT-01 | әкімші бар | `/login` ашу; дұрыс логин/құпиясөз енгізу | dashboard ашылады, әкімші мәзірі көрінеді |
| UAT-02 | әкімші бар | қате құпиясөзбен кіру | жүйе кіргізбейді, жалпы қате хабарын береді |
| UAT-03 | байланыс бұрын қолданылмаған | `/register` арқылы аты, байланыс, 8+ таңбалы құпиясөз енгізу | тіркелу аяқталып, клиент өз кабинетіне кіре алады |
| UAT-04 | әкімші кірген | «Жаңа клиент» ашу; аты мен бірегей байланысты сақтау | клиент тізімде бір рет пайда болады |
| UAT-05 | кемінде бір клиент бар | атының бөлігімен, кейін байланыспен іздеу | сәйкес клиент екі іздеуде де табылады |
| UAT-06 | клиент бар | 8 келуге лимитті абонемент ашу; кейін басқа кезеңге лимитсіз абонемент ашу | екі кезең тарихта, түрі мен мерзімі дұрыс көрінеді |
| UAT-07 | белсенді абонемент бар | бір `request_id`-мен ұзартуды екі рет жіберу | тек бір жаңа кезең жасалады, екінші сұрау қайталану деп танылады |
| UAT-08 | абонемент бар | 20 000 ₸ төлемді бір `request_id`-мен екі рет жіберу | бір төлем сақталады, карта дерегі сұралмайды |
| UAT-09 | UAT-03 клиенті бар | клиент логинімен кіру | тек өзінің аты мен абонемент тарихы көрінеді |
| UAT-10 | клиент кірген | `/clients` мекенжайын тікелей ашу | 403 алынады, әкімші деректері көрсетілмейді |

## Жалпы өту шарты

Сценарий `PASS` болады, егер күтілетін нәтиже толығымен орындалып, дерек қайталанбаса және тексерушіге қосымша түсіндіру қажет болмаса. Басқа нәтиже — `FAIL` немесе `BLOCKED`, кейін GitHub Issue ашылады.
