# Басқа командаға арналған UAT нұсқаулығы

## Қалай қатысу керек

1. FitClub командасы берген стенд сілтемесін браузерде ашыңыз.
2. [10 сценарийді](uat-scenarios.md) ретімен орындаңыз.
3. Әр сценарий үшін `PASS`, `FAIL` немесе `BLOCKED` таңдаңыз.
4. Нақты көрген нәтиже мен түсініксіз жерді қысқа жазыңыз.
5. Соңында үш шешімнің бірін таңдаңыз: қабылданды, ескертумен қабылданды, қабылданбады.

Тексеру шамамен 15–20 минут алады. Бағалауға код білу қажет емес. Нақты клиент дерегін енгізбеңіз; мысалы, `uat-01@example.test` қолданыңыз.

## Стендке кіру

- Бір компьютерде: `http://127.0.0.1:5000`
- Бір Radmin VPN желісінде: `http://<RADMIN-IP>:5000`
- Бір Wi-Fi желісінде: `http://<LAN-IP>:5000`

Нақты IP адрес GitHub-та жарияланбайды. FitClub өкілі UAT алдында `ipconfig` арқылы тиісті IPv4 адресін алып, `/health` арқылы сілтемені тексереді және оны қабылдаушыға жеке береді. Әкімші логині мен уақытша құпиясөз де тек орындаушыға жеке беріледі.

## Нәтижені тіркеу

Нәтиже [UAT хаттамасына](uat-protocol.md) енгізіледі. `FAIL` немесе маңызды ұсыныс болса, Severity және Priority көрсетілген GitHub Issue ашылады. Қабылдаушы команда/қатысушы атауы мен күн міндетті.
