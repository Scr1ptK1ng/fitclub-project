# ЛЗ11 қорғау картасы

## Ануар — қабылдау және инцидент коммуникациясы

Түсіндіретіні: сапа тек тестердің жұмысы емес; UAT бизнеске жүйенің жарамдылығын тексертеді. 10 сценарий дайын, бірақ басқа команда орындамайынша хаттама `NOT RUN` күйінде қалады. Инцидент кезінде Ануар әсерді тіркеп, жаңартуларды жеткізеді және кінәлі іздемейтін postmortem жүргізеді.

Көрсететіні: `uat-scenarios.md`, `uat-protocol.md`, `postmortem.md`.

## Айдос — автоматтандыру және қалпына келтіру

Түсіндіретіні: pytest бизнес-ережелерді, Playwright нақты браузер жолдарын, k6 жүктемені тексереді. `/health` тек веб-сервер емес, дерекқор сұрауы орындалғанда 200 қайтарады. Docker Compose ортаны қайталап іске қосуға мүмкіндік береді.

Көрсететіні: pytest нәтижесі, UI smoke нәтижесі, k6 summary, `/health`, Docker Compose.

## Әділбек — QA және эксплуатациялық бақылау

Түсіндіретіні: Severity пайдаланушыға әсерді, Priority түзету кезегін білдіреді. Exit criteria орындалмайынша релиз дайын емес. Uptime Kuma ақауды табады, ал runbook бірдей қалпына келтіру ретін береді. Қалпына келген соң міндетті түрде regression жасалады.

Көрсететіні: `test-strategy.md`, Uptime Kuma monitor, `runbook.md`.

## Негізгі қорытынды

ЛЗ11 нәтижесі — «тест бар» деген сөз емес. Жоба ақауды алдын ала тексереді, пайдаланушы арқылы қабылдайды, істен шыққанда байқайды, қалпына келтіреді және қайталанбауы үшін нақты әрекет тағайындайды.
