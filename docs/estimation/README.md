# FitClub — ЛЗ6: бағалау және ықтимал мерзім

Бұл бумада FitClub MVP мерзімін ықтималдықпен бағалау материалдары берілген.

## Негізгі нәтиже

- Monte Carlo: 10 000 іске қосу, backlog — 15 user story.
- Тарихи үлгі: оқытушының 6-дәрісіндегі апталық throughput қатары — `3, 8, 4, 10, 2, 7, 9, 5, 6, 6`.
- P50 және P70 — 3 апта; P85 және P95 — 4 апта.
- Басталу күні 08.10.2026 болса, P50/P70 — 29.10.2026, P85/P95 — 05.11.2026.
- Бұл күндер FitClub-тың нақты velocity-іне емес, сыртқы оқу үлгісіне сүйенеді. Сондықтан тапсырыс берушіге берілетін жұмыс базасы — ЛЗ5-тегі 16.12.2026 межесі; 22.10.2026 күні екі нақты аптадан кейін қайта болжанады.

## Файлдар

- `FitClub_LZ6_monte_carlo.ipynb` — қайта іске қосылатын симуляция және графиктер.
- `FitClub_LZ6_forecast.xlsx` — бастапқы дерек, ықтималдық кестесі, диаграммалар және Planning Poker.
- `FitClub_LZ6_customer_estimate.pptx` — тапсырыс берушіге арналған бір слайд.
- `methodology-and-results.md` — әдіс, нәтиже және детерминистік бағамен салыстыру.
- `planning-poker.md` — 10 story бойынша алдын ала дауыс моделі.
- `customer-estimate.md` — тапсырыс берушіге айтылатын қысқа тұжырым.
- `defense-lz6.md` — үш қатысушының жеке қорғау сценарийі.

## Академиялық адалдық ескертуі

Planning Poker кестесіндегі дауыстар — рөлдер көзқарасын көрсетуге арналған алдын ала модель. Команда нақты сессия өткізіп, дауыстарды растауы немесе түзетуі керек. Расталғанға дейін олар нақты жиналған дауыс ретінде ұсынылмайды.
