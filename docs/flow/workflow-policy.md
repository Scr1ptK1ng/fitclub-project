# FitClub жұмыс ағынының саясаты

## Тақта бағандары

| Баған | WIP лимиті | Бағанға кіру шарты | Бағаннан шығу шарты |
|---|---:|---|---|
| Backlog | жоқ | құндылығы бар кандидат жұмыс | Product Manager басымдық берді |
| Ready | 5 | DoR толық орындалды | жауапты адам жұмысты бастады |
| In Progress | 3 | owner бар, WIP бос | іске асыру аяқталды, өзіндік тексеру өтті |
| Review | 2 | өзгеріс пен evidence бар | review ескертулері жабылды |
| Test | 2 | review аяқталды, acceptance criteria тексеріледі | тест өтті немесе defect ашылды |
| Waiting for customer | 1 | шешім/қабылдау оқытушыға тәуелді | жауап decision log-қа жазылды |
| Done | жоқ | DoD толық орындалды | соңғы күй |

WIP лимитіне жеткенде жаңа жұмыс алынбайды. Команда алдымен тұрған карточканы келесі кезеңге өткізуге көмектеседі.

## Definition of Ready

Карточка `Ready` күйіне тек мына жағдайда өтеді:

- пайдаланушы рөлі мен құндылығы түсінікті;
- acceptance criteria және кемінде бір теріс сценарий бар;
- қолданылатын NFR көрсетілген;
- сыртқы тәуелділік анықталған;
- жұмыс бір спринтке сыяды;
- owner анықталған;
- тест дәлелінің түрі алдын ала жазылған.

## Definition of Done

Карточка `Done` күйіне тек мына жағдайда өтеді:

- acceptance criteria толық орындалды;
- өзгеріс main branch-ке қосылды немесе құжат main-де жарияланды;
- кемінде бір review жасалды;
- қолданылатын тесттер өтті;
- қауіпсіздік/дерек тұтастығы талабы бұзылмады;
- README немесе пайдаланушыға әсер ететін құжат жаңартылды;
- GitHub issue-де дәлелге сілтеме бар;
- issue жабылды.

## Қызмет көрсету кластары

| Класс | Лимит | Қолданылуы |
|---|---:|---|
| Standard | жалпы WIP ішінде | жоспарланған өнім жұмысы |
| Fixed date | 1 | қорғау күнімен шектелген жұмыс |
| Expedite | 1 | қауіпсіздік, дерек жоғалуы немесе блоктаушы ақау |

`Expedite` «бәрі шұғыл» режимі үшін қолданылмайды. Оны Айдос ашады және себебі issue-де жазылады.

## Күйді GitHub-та белгілеу

GitHub issue-ге бір ғана `status:*` label беріледі. Күй ауысқанда ескі status label алынып, жаңа label қосылады. Осы label оқиғалары метриканың бастапқы дерегі болады.
