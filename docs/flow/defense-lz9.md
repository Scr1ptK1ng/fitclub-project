# ЛЗ9 қорғау сценарийі

## Ануар — процесс және Sprint Goal

«ЛЗ9 мақсаты — тапсырмалар тізімін ғана көрсету емес, жұмыстың жүйе арқылы қалай өткенін өлшеу. Біз Backlog, Ready, In Progress, Review, Test, Waiting for customer және Done күйлерін қолдандық. Әр белсенді бағанда WIP лимиті бар. Sprint 1 мақсаты — әкімші кіріп, клиентті тіркеп және оны іздей алатын тік срез жасау болды. Бес карточка аяқталды».

Көрсетеді: `workflow-policy.md`, Sprint 1 milestone және Flow Board.

## Айдос — өнім және метрика

«Sprint 1-де throughput 5 болды, орташа cycle time 0,033 сағат, p85 — 0,072 сағат. Ең ұзақ карточка — жүйеге кіру. Ретрода бір ғана өзгеріс алдық: developer WIP-ын үштен бірге азайттық. Sprint 2-де #5, #6 және #22 қатаң кезекпен орындалды. Орташа cycle time 0,017 сағатқа, p85 0,018 сағатқа түсті. Бұл нақты GitHub event экспортынан алынған, бірақ жеделдетілген оқу прогоны болғандықтан нәтижені апталық өнімділік деп көрсетпейміз».

Көрсетеді: `two-sprint-report.md`, `cfd-comparison.svg`, екі `export-summary.json`.

## Әділбек — сапа және дәлел

«Sprint 1 соңында үш автоматтандырылған тест, Sprint 2 соңында алты тест өтті. Олар дұрыс және қате логинді, рұқсатсыз кіруді, клиент тіркеуді, дубльді, іздеуді, абонемент күндері мен лимитін, идемпотентті ұзартуды және қайталанбайтын төлемді тексереді. Әр issue-де commit пен тест дәлеліне сілтеме бар. Done күйі тек тесттен кейін қойылды».

Көрсетеді: `sprint-1-test-protocol.md`, `tests/test_app.py`, жабылған GitHub issues.

## Қысқа сұрақтарға жауап

**CFD деген не?** Әр уақыт нүктесінде қанша карточка әр күйде тұрғанын көрсететін жинақталған ағын диаграммасы.

**p85 деген не?** Карточкалардың 85%-ы осы уақыттан кеш емес аяқталғанын көрсететін cycle time перцентилі.

**Неге throughput 5-тен 3-ке түсті?** Sprint 2 scope-ында үш карточка болды және үшеуі де жабылды. Scope әртүрлі болғандықтан абсолют санды өнімділіктің төмендеуі деп түсіндірмейміз.

**Неге екі апта емес?** Бұл 29.10.2026 күні орындалған жеделдетілген оқу прогоны. Timestamp өзгертілмеген; есепте шектеу ашық көрсетілген.
